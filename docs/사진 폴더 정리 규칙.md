# 문제 사진 폴더 정리 규칙

문제집을 찍거나 스캔한 사진은 아래 규칙대로 폴더에 모은 뒤 프로그램에 등록합니다. 규칙대로 정리하면 등록할 때 **교재명과 학년이 자동으로 채워집니다.**

## 한눈에 보기

```
문제사진\
├─ 중1\
├─ 중2\
│   ├─ 쎈 중2-1\
│   │   ├─ 2026-10-04 12-18쪽\
│   │   │   ├─ IMG_0001.jpg
│   │   │   ├─ IMG_0002.jpg
│   │   │   └─ ...
│   │   └─ 2026-10-11 19-25쪽\
│   └─ 율현중 2025-1 중간 기출\
│       └─ 2026-10-05\
├─ 중3\
├─ 고1\
├─ 고2\
├─ 고3\
└─ 기타\
```

폴더는 **학년 → 교재 → 등록 한 번** 순서로 세 단계입니다.

## 1단계: 학년 폴더

- 이름은 아래 7개 중 하나로만 씁니다. 띄어쓰기 없이 그대로 씁니다.
  - `중1` `중2` `중3` `고1` `고2` `고3` `기타`
- `중학교2학년`, `중 2`, `2학년`처럼 다르게 쓰면 학년이 자동으로 채워지지 않습니다.
- 학년이 애매한 자료(예: 여러 학년 공용 자료)는 `기타`에 넣고, 등록할 때 학년을 직접 고릅니다.

## 2단계: 교재 폴더

교재 폴더 이름이 그대로 문제은행의 **교재명**이 되고, 문제은행에서 교재로 찾을 때 이 이름을 씁니다. 같은 교재는 항상 똑같은 이름으로 씁니다.

| 자료 종류 | 이름 짓는 법 | 예 |
| --- | --- | --- |
| 시판 교재 | `교재명 학년-학기` | `쎈 중2-1`, `개념원리 고1 공통수학1` |
| 학교 기출 | `학교명 연도-학기 시험 기출` | `율현중 2025-1 중간 기출` |
| 학원 자체 자료 | `학원 자료명` | `학원 여름특강 3주차` |

- 처음 등록한 이름을 계속 씁니다. `쎈 중2-1`로 시작했으면 `쎈중2-1`이나 `쎈 2-1`로 바꾸지 않습니다. 이름이 조금이라도 다르면 다른 교재로 저장됩니다.
- 등록 화면에서 교재명 칸에 비슷한 이름이 이미 있으면 목록에 뜹니다. 목록의 이름을 고르는 것이 가장 안전합니다.

## 3단계: 등록 폴더

- 한 번에 등록할 사진을 한 폴더에 모읍니다. **폴더 하나를 등록 한 번**으로 생각하면 됩니다.
- 이름은 `날짜 쪽범위`로 짓습니다. 예: `2026-10-04 12-18쪽`. 쪽 범위를 모르면 날짜만 써도 됩니다.
- 이 이름은 선생님들이 알아보기 위한 것이라 프로그램이 읽지 않습니다.
- 한 폴더에는 30장 이내를 권장합니다. 검수를 나눠서 하기 편합니다.

## 사진 규칙

**파일**

- **JPG**나 **PNG**만 씁니다.
- **아이폰**: 설정 → 카메라 → 포맷 → **"높은 호환성"** 을 선택해 두세요. 기본값(HEIC)은 프로그램이 받지 않습니다.
- 파일 이름은 바꾸지 않아도 됩니다. 프로그램은 **파일 이름 순서**로 처리하는데, 폰이나 복합기는 찍은 순서대로 이름을 붙이므로 **쪽 순서대로 찍기만 하면** 됩니다.

**찍는 법**

- 사진 한 장에는 **한 쪽**만 담습니다. 펼친 두 쪽을 한 번에 찍지 않습니다.
- 쪽 전체가 다 들어오게 찍습니다. 문제 번호가 잘리면 문제를 나누지 못합니다.
- **글씨가 작은 교재**(한 쪽에 문제가 빽빽한 프린트, 작은 표)는 쪽 전체 대신 **반쪽이나 한 단씩 가까이** 찍습니다. 사진 속 글자가 작으면 글자를 틀리게 읽거나 문제를 통째로 놓칩니다. 찍은 뒤 확대해서 본문 글자가 또렷하게 읽히면 됩니다.
- 책 가운데 접히는 부분 근처의 휘어진 줄은 잘못 읽기 쉽습니다. 책을 손으로 눌러 평평하게 폅니다.
- 옆 쪽이나 옆 단이 사진 가장자리에 들어오지 않게 합니다. 옆 글자가 문제에 섞입니다.
- 책을 평평하게 펴고 위에서 정면으로 찍습니다. 손이나 폰 그림자가 글자를 가리지 않게 합니다.
- 찍은 뒤 확대해서 작은 글자(지수, 분수)가 선명한지 확인합니다.
- **풀이 흔적이 없는 깨끗한 책**을 찍습니다. 연필 자국이 있으면 지우개로 지운 뒤 찍습니다. 프로그램은 손글씨를 자동으로 지우지 못합니다.
  - 특히 **보기 번호 위의 체크(✓)·동그라미**는 보기 번호를 망가뜨립니다(②가 "-"로 읽힘). 학생이 푼 시험지는 깨끗한 원본을 구해서 찍습니다.
  - 표 안에 적은 답은 표 내용으로 섞여 들어갑니다.
- 해설·정답 쪽은 찍지 않습니다. 정답은 검수할 때 직접 입력합니다.
- 복합기 스캔이 가능하면 스캔이 가장 깨끗합니다(300dpi, 컬러 또는 회색조).

**한 문제가 두 쪽에 걸친 경우**

- 그대로 두 쪽을 각각 찍으면 됩니다. 검수 화면에서 "다음 사진과 합치기"로 한 문제로 이어 붙입니다.

## 사진을 PC로 옮기는 법

- 폰 사진은 카카오톡 PC버전(나에게 보내기, "원본"으로 전송), USB 케이블, 구글 드라이브 중 편한 방법으로 PC의 `문제사진` 폴더로 옮깁니다.
- 카카오톡으로 보낼 때 **"원본 화질"** 을 꼭 선택합니다. 일반 화질은 사진이 줄어들어 인식이 나빠집니다.
- `문제사진` 폴더는 서버 PC의 `D:\문제사진`에 두는 것을 권장합니다. 다른 PC에서 정리했다면 등록 화면의 "폴더 선택"으로 올리면 됩니다.

## 등록하고 난 뒤

- 등록한 폴더는 지우지 않고 그대로 둡니다. 프로그램 안에도 사본이 저장되지만, 원본 사진이 있으면 나중에 다시 확인하기 좋습니다.
- **실수로 같은 폴더를 두 번 등록해도 괜찮습니다.** 이미 처리한 사진은 다시 인식하지 않으므로 비용이 들지 않습니다.
- 등록 후 교재명이나 학년을 잘못 넣었으면 폴더 이름을 바꾸지 말고 프로그램 안에서 고칩니다. 폴더 이름을 바꿔도 이미 등록된 문제에는 반영되지 않습니다.

## 자주 하는 실수

| 실수 | 결과 | 이렇게 하세요 |
| --- | --- | --- |
| 학년 폴더를 `중2학년`으로 만듦 | 학년이 자동으로 안 채워짐 | `중2`처럼 정해진 7개 이름만 사용 |
| 같은 교재를 `쎈 중2-1`, `쎈중2-1`로 섞어 씀 | 문제은행에서 다른 교재로 나뉨 | 등록 화면 목록에서 기존 이름 고르기 |
| 펼친 두 쪽을 한 장에 찍음 | 문제 나누기가 틀어짐 | 한 장에 한 쪽 |
| 카카오톡 일반 화질로 전송 | 작은 글자 인식 오류 | "원본 화질"로 전송 |
| 아이폰 HEIC 사진 | 등록 거부 | 카메라 포맷을 "높은 호환성"으로 |
