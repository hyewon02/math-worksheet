# 새 문제지 형식 만들기 (AI 프롬프트)

문제지 프로그램에 들어 있는 형식 말고 다른 모양의 문제지가 필요할 때, AI에게 형식 파일(.docx)을 만들게 하는 방법입니다. Word를 직접 다룰 필요가 없습니다.

## 준비물

1. **파일을 만들 수 있는 AI 대화창**: 예) Claude(claude.ai)에서 파일 생성 기능을 켠 상태. 결과로 .docx 파일을 내려받을 수 있어야 합니다.
2. **출발점 형식 파일**: 서버 PC의 프로그램 → 설정 → 형식 파일 → 만들려는 모양과 가장 비슷한 형식의 "내려받기".
3. **원하는 시험지 모양 사진(있으면)**: 따라 하고 싶은 시험지를 찍은 사진 1\~2장. 문제 내용은 상관없고 머리말·글꼴·배치가 보이면 됩니다.

## 순서

1. AI 대화창을 새로 엽니다.
2. 출발점 형식 파일과 시험지 사진을 첨부합니다.
3. 아래 **"복사할 프롬프트"** 상자 안의 내용을 전부 복사해 붙여 넣습니다.
4. 맨 위 **[원하는 모양]** 부분만 선생님 말로 고쳐 씁니다.
5. AI가 만든 .docx를 내려받습니다. AI가 마지막에 알려주는 **"유형별 풀이 공간"** 숫자도 메모해 둡니다.
6. 서버 PC의 프로그램 → 설정 → 형식 파일 → "새 형식 등록"에서 파일을 올리고, 메모한 풀이 공간 숫자를 입력합니다.
7. 등록되면 미리보기 문제지가 나옵니다. 모양을 확인합니다.
   - **등록이 거부되면**: 화면에 나온 오류 문장을 그대로 복사해 같은 AI 대화창에 붙여 넣고 "이 오류를 고쳐줘"라고 쓰면 됩니다.
   - **모양이 마음에 안 들면**: 같은 대화창에 "문제 글자를 조금 더 크게", "머리말에 학원 로고 자리 빼줘"처럼 말로 요청하고 다시 등록합니다.

## 복사할 프롬프트

````text
너는 Word(.docx) 서식 전문가야. 첨부한 docx는 수학 문제지 프로그램이 쓰는 "형식 파일"이야.
프로그램은 Pandoc의 --reference-doc로 이 파일의 스타일·머리말·꼬리말·페이지 설정만 가져다 쓰고,
본문 내용은 쓰지 않아. 아래 [원하는 모양]대로 서식을 바꾼 새 docx를 만들어 줘.
이 파일은 프로그램이 자동으로 검사하므로 [반드시 지킬 규격]을 정확히 지켜야 해.

========================================
[원하는 모양]  ← 선생님이 고쳐 쓰는 부분
========================================
- 용도: (예: 내신 대비 실전 모의고사)
- 단 수: (예: 2단 / 1단)
- 글꼴과 크기: (예: 본문 맑은 고딕 10pt, 문제 번호 굵게)
- 머리말 모양: (예: 첨부 사진처럼 위에 큰 제목, 오른쪽에 이름 칸)
- 기타 요청: (예: 문제 사이 구분선 없이, 여백은 조금 좁게)
- 첨부한 시험지 사진이 있으면 그 모양을 최대한 따라 해 줘.

========================================
[반드시 지킬 규격]
========================================

1. 출발점
- 첨부한 docx를 출발점으로 수정해. 새로 만들지 마.
- 기존 스타일은 지우지 마(Pandoc이 쓰는 Normal, Body Text, First Paragraph, Compact,
  Image Caption, Captioned Figure 등 포함). 필요한 것만 수정하고 없는 것만 추가해.

2. 필수 스타일 13개
- 스타일 "이름"(styles.xml의 w:name)은 아래 영문 그대로, 대소문자까지 똑같이. 번역하거나 바꾸지 마.
- 종류(단락/문자/표)도 아래와 같아야 해.

| 이름 | 종류 | 역할과 필수 설정 |
| Problem | 단락 | 문제 본문. 문제 번호와 탭이 앞에 붙으므로 내어쓰기(hanging, 약 0.6cm)와 그 위치의 탭 1개. 줄 나눔 방지(keepLines)와 다음 단락과 함께(keepNext) 켜기 |
| ProblemNumber | 문자 | 문제 번호. 굵게 |
| GroupStem | 단락 | 여러 문제가 공유하는 공통 지문("[3~4] 다음을 읽고…"). 다음 단락과 함께(keepNext) |
| Choices5 | 단락 | 보기 ①~⑤를 한 줄에 5개. 왼쪽 들여쓰기 = Problem의 내어쓰기와 같게. 남은 단 너비를 5등분한 위치에 왼쪽 탭 4개 |
| Choices3 | 단락 | 보기를 한 줄에 3개(3+2). 왼쪽 들여쓰기는 위와 같고, 남은 단 너비를 3등분한 위치에 왼쪽 탭 2개 |
| Choices1 | 단락 | 보기를 한 줄에 1개. 왼쪽 들여쓰기는 위와 같음 |
| BogiTitle | 단락 | "<보 기>" 제목. 가운데 정렬 |
| BogiBox | 단락 | <보기> 상자 내용. 네 면 테두리. 연속된 단락이 한 상자로 합쳐지도록 모든 단락에 똑같은 테두리 설정 |
| Figure | 단락 | 그림 단락. 가운데 정렬, 다음 단락과 함께(keepNext) |
| Table | 표 | 문제 속 표. 전체 테두리, 가운데 정렬 |
| Answer | 단락 | 정답지의 "정답 ③" 줄. 빨간색 |
| CorrectChoice | 문자 | 정답지에서 정답 보기 강조. 빨간색, 굵게 |
| AnswerTable | 표 | 정답지 첫 쪽의 빠른 정답표. 전체 테두리, 본문보다 약간 작은 글자 |

- 탭 위치는 실제 단 너비로 계산해. 단 너비 = (용지 너비 − 왼쪽·오른쪽 여백 − 단 간격) ÷ 단 수.
  예) A4(21cm), 여백 1.8cm씩, 2단, 간격 1cm → 단 너비 약 8.2cm.
- 한글 글꼴은 rFonts의 eastAsia에도 지정해(그래야 한글에 적용됨).
- 수식 글꼴(Cambria Math)은 바꾸지 마.

3. 페이지 설정
- 따로 요청이 없으면 A4 세로(w:pgSz w=11906, h=16838).
- 단 수는 [원하는 모양]대로. 2단이면 단 사이 구분선(w:cols의 w:sep="1")을 켜고 간격 약 1cm.
- 첫 쪽 머리말을 다르게(w:titlePg) 설정해.
- 페이지 설정은 본문 마지막의 구역 설정(body의 마지막 w:sectPr)에 있어야 해.
  Pandoc이 여기서 페이지 설정을 가져가. 본문 내용을 지우더라도 이 구역 설정은 반드시 남겨.

4. 머리말·꼬리말과 빈칸 4개
- 빈칸은 아래 4개를 정확히 이 글자 그대로 넣어(중괄호 두 개, 한글 이름, 띄어쓰기 없음).
  {{학원명}}  {{시험제목}}  {{날짜}}  {{문제지번호}}
- 첫 쪽 머리말: {{학원명}}, {{시험제목}}, {{날짜}}, 그리고 학생이 손으로 쓰는 "이름: ________" 칸.
- 둘째 쪽부터 머리말: {{시험제목}}과 {{학원명}}을 한 줄로.
- 꼬리말(첫 쪽과 나머지 모두): 가운데에 쪽 번호(PAGE 필드), 한쪽 구석에 작게 {{문제지번호}}.
- 아주 중요: 각 빈칸은 XML에서 하나의 w:t 안에 끊김 없이 들어가야 해.
  "{{", "시험제목", "}}"처럼 여러 w:r로 쪼개지면 프로그램이 빈칸을 찾지 못해.
  빈칸 글자 중간에 서식 변경, 맞춤법 표시(w:proofErr), 책갈피를 넣지 마.

5. 본문
- 본문은 문제지에 쓰이지 않아. 각 필수 스타일을 적용한 짧은 견본 단락만 남겨.
  (예: Problem 스타일로 "1  함수 f(x)의 최솟값은?", Choices5 스타일로 "①1 ②2 ③3 ④4 ⑤5" 등)

========================================
[완성 후 스스로 검사하고 결과를 보고해]
========================================
docx 압축을 풀어 XML을 직접 확인하고, 아래 표를 채워서 보여줘. 하나라도 실패면 고친 뒤 다시 검사해.

| 검사 항목 | 결과 |
| styles.xml에 필수 스타일 13개가 정확한 이름과 종류로 있음 (빠진 것 나열) | |
| 머리말·꼬리말 XML에서 빈칸 4개가 각각 하나의 w:t 안에 그대로 있음 | |
| body 마지막 w:sectPr에 용지 크기, 여백, 단 수, (2단이면) 구분선, w:titlePg가 있음 | |
| 첫 쪽 머리말과 기본 머리말이 따로 연결되어 있음 (headerReference type="first"와 "default") | |
| Choices5·Choices3의 탭 위치를 어떤 단 너비로 계산했는지 | |

마지막으로 아래 두 가지를 알려줘.
1. 파일 이름: "형식_(용도).docx"로 저장해서 내려받을 수 있게.
2. 유형별 풀이 공간 추천값(cm): 이 형식의 글자 크기와 단 높이를 기준으로
   객관식 ___cm, 단답형 ___cm, 서술형 ___cm. (프로그램에 형식을 등록할 때 입력하는 값이야)
````

## 참고: 프로그램이 등록할 때 검사하는 것

AI가 만든 파일을 올리면 프로그램이 아래를 확인합니다. 하나라도 빠지면 등록되지 않고 무엇이 빠졌는지 알려줍니다.

- 필수 스타일 13개(이름과 종류)
- 머리말·꼬리말의 빈칸 4개: `{{학원명}}`, `{{시험제목}}`, `{{날짜}}`, `{{문제지번호}}`
- 통과하면 객관식·단답형·서술형·묶음 문제·그림·표가 든 샘플로 미리보기 문제지를 만들어 보여줍니다.
