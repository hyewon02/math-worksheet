# 원고 형식 (문제지 마크다운)

문제지 원고는 프로그램이 문제지 스냅샷에서 자동으로 조립하는 마크다운이다. 서식 정보는 넣지 않고 "무엇이 문제·보기·정답인지"만 표시한다. 서식은 형식 파일(reference.docx)과 Lua 필터(`worksheet/filters/worksheet.lua`)가 정한다. 설계서 8장 "원고 형식"을 구체화한 문서이며, 원고 조립(Java), Lua 필터, 역변환 비교가 모두 이 규칙을 따른다.

- Pandoc 입력 형식: `markdown+tex_math_single_backslash` (Mathpix식 `\(...\)`, `\[...\]` 수식)
- 예시: [worksheet/samples/sample-01.md](../worksheet/samples/sample-01.md)

## 구역

| 구역 | 위치 | 속성 | 내용 |
| --- | --- | --- | --- |
| `::: {.problem}` | 최상위 또는 `group` 안 | `num`(필수, 번호), `type`(`choice`/`short`/`essay`), `space`(풀이 공간, cm 단위 문자열 예: `3cm`), `source`(선택, 출처) | 문제 본문 단락, 그림, 표, 아래 하위 구역 |
| `::: choices` | `problem` 안 | 없음 | 한 단락. 보기 하나가 한 줄이고 `①`~`⑤`로 시작 |
| `::: bogi` | `problem` 안, `choices` 앞 | 없음 | `<보기>` 상자 내용. 한 줄이 한 항목(`ㄱ.`, `ㄴ.` …) |
| `::: answer` | `problem` 안, 마지막 | 없음 | 정답. 객관식은 `①`~`⑤` 하나, 단답형·서술형은 최종 답(수식 가능). 정답 미입력이면 구역 자체를 넣지 않는다 |
| `::: {.group}` | 최상위 | `range`(예: `9~10`) | 공통 지문 단락(그림 가능) 뒤에 하위 `problem`들 |

```markdown
::: {.problem num="1" type="choice" space="1cm"}
함수 \(f(x)=x^{2}-4x+1\)의 최솟값은?

::: choices
① \(-4\)
② \(-3\)
:::

::: answer
②
:::
:::
```

설계서 8장 예시는 `choices`를 `problem`과 나란히 두었지만, 문제 하나를 구역 하나로 묶어야 Lua 필터가 정답 줄·풀이 공간 위치를 정하고 역변환 비교가 문제 단위로 자를 수 있어 **안에 넣는 방식**으로 정했다.

## 조립 규칙 (원고 조립 코드가 지킬 것)

- **본문 글자는 그대로 넣는다.** 바꾸는 것은 아래 이스케이프와 그림 표시 치환뿐이다(CLAUDE.md 절대 원칙 1).
- **`<`, `>` 이스케이프**: 수식 구간(`\(...\)`, `\[...\]`) **밖의** `<`, `>`만 앞에 `\`를 붙인다. 붙이지 않으면 `<보기>`가 HTML 태그로 인식되어 사라진다. 수식 안에 붙이면 LaTeX가 깨지므로 수식 안은 건드리지 않는다.
- **그림**: 본문의 `[그림:p0123_1]` 표시를 `![](images/p0123_1.png){width=4.1cm}`로 바꾼다. 크기는 반드시 cm(2단 기준 단 너비 약 8.2cm × 선택 비율).
- **풀이 공간**: `space`에는 최종 cm 값을 넣는다(형식의 유형별 기본값 × 작게 0.5 / 보통 1 / 크게 2).
- 번호, 탭, `<보 기>` 제목, 정답 줄, 정답표는 원고에 넣지 않는다. Lua 필터가 붙인다.

## Lua 필터가 하는 일 (요약)

| 대상 | 학생용 | 정답지(`-M answers=true`) |
| --- | --- | --- |
| `problem` | 첫 단락 앞에 번호 + Word 탭, `Problem` 스타일. 뒤에 `space` 높이 빈 단락 | 같음 |
| `choices` | 가장 긴 보기 너비로 `Choices5` / `Choices3` / `Choices1`(기준 칸 수는 형식 설정, 없으면 9/15) | 정답 보기를 `CorrectChoice`로 강조 |
| `bogi` | `BogiTitle`(`<보 기>`) + `BogiBox` | 같음 |
| `answer` | 제거 | `Answer` 스타일 "정답 ②". 구역이 없으면 "정답 미입력 · 출처: …" |
| `group` | 공통 지문 `GroupStem`, 하위 문제까지 "다음 단락과 함께" | 같음 |
| 문서 앞 | 없음 | `AnswerTable` 빠른 정답표 |

보기 너비: 한글 2칸, 영문·숫자·기호 1칸, 수식은 LaTeX 명령어(`\frac` 등)와 중괄호를 뺀 글자 수. 맨 앞 `①`~`⑤`와 그 뒤 공백은 세지 않는다.
