## 작성 양식

파일 이름: `YYYY-MM-DD-주제.md` (같은 날 여러 편이면 주제로 구분)

```markdown
# YYYY-MM-DD 제목

- 단계: 로드맵 n
- 관련 커밋: <해시>

## 한 일
## 결정과 이유        (고려한 대안, 버린 이유)
## 문제와 해결        (증상 → 원인 → 해결 → 배운 점)
## 면접 포인트        (예상 질문과 답변 요지)
## 다음 할 일
```
